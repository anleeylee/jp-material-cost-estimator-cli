# Contributing / 貢献ガイドライン

Thank you for considering a contribution to **jp-material-cost-estimator-cli**.

## Japanese

1. Fork this repository and create a topic branch.
2. Keep formulas traceable: every constant or rule must carry its source reference.
3. Do not impute unverified values; leave them null and mark the record accordingly.
4. Add or update unit tests under `tests/` and run `python -m unittest discover -s tests`.
5. Open a Pull Request describing the change, its evidence, and any assumptions.

## English

The calculation portal behind this project is [SumaiTools（住まいの建築・リフォーム・DIY 計算器サイト）](https://sumaitools.com/).
This CLI is an offline companion; please keep results labelled as estimates, not guarantees.

## Code of conduct

Be respectful, cite sources, and disclose limitations.
